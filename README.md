## 🚀 Highlights

- 🍟 **Delicious UI:** High-quality food imagery with a bold, appetizing color palette.
- 📱 **Fully Responsive:** Optimized for every device—from mobile phones to large desktops.
- ⚡ **Interactive Elements:** Smooth hover effects, dropdown menus, and a sleek navigation bar.
- 📑 **Clean Architecture:** Well-structured HTML5 and organized CSS for easy maintenance.

## 🛠️ Tech Stack

- **HTML5:** Semantic tags for better SEO and accessibility.
- **CSS3:** Custom layouts using Flexbox/Grid, and creative typography (Bebas, Pacifico).
- **Assets:** Optimized images for fast loading speeds.
